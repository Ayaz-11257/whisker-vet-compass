# Whisker Vet Compass

Build a premium, modern and fully responsive animal healthcare discovery platform called "Practo for Animals".

PRODUCT PURPOSE:
Help pet owners discover veterinary clinics, animal hospitals, boarding facilities, diagnostic centres, animal ambulances and animal welfare NGOs.

DESIGN DIRECTION:

Professional healthcare marketplace aesthetic.

Primary colour: teal (#087E8B).

Soft mint backgrounds, white cards and subtle orange accents.

Modern typography.

Rounded cards, subtle shadows and clean spacing.

Friendly but professional visual identity.

Excellent mobile responsiveness.

HOMEPAGE STRUCTURE:

Navigation:

Practo for Animals logo with paw icon.

Home, Explore Services, For Providers, About.

Prominent "List Your Business" button.

Hero section:

Headline: "Better Care for Every Paw."

Supporting text explaining the animal-care discovery platform.

Large search bar with location and service inputs.

Primary CTA: "Find Animal Care".

Secondary CTA: "Explore Services".

Beautiful animal healthcare imagery.

Service categories:

Veterinary Clinics.

Animal Hospitals.

Pet Boarding.

Diagnostics.

Ambulance Services.

Animal Welfare NGOs.

Featured providers:
Create realistic-looking sample provider cards with clearly identified demo data, including provider name, location, services, operating hours and contact action.

Emergency care section:
Prominently help users discover emergency veterinary facilities and available ambulance services. Do not imply guaranteed real-time emergency availability.

Provider registration:
A section encouraging veterinary businesses to list their services.

Trust and information:
Explain how the platform helps pet owners discover animal-care services.

Footer:
Navigation links, contact information placeholder and Submit a Correction link.

INTERACTIONS:

Search input.

Service category selection.

Provider cards.

Navigation links.

Working CTA buttons.

Responsive mobile menu.

IMPORTANT:
Prioritise usability, visual quality, accessibility and a polished startup-level design. Do not invent real clinic reviews, verified credentials or real provider details. Use clearly labelled demonstration data.
